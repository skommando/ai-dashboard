# 180 天会话登录实施计划

**设计：** [会话登录规格](../specs/2026-09-29-session-login.md)。用户已明确授权 180 天会话、新 20 位复杂密码、移除 Basic、项目令牌独立上报及统一登录失败正文。生产凭据只能在仓库外准备和发布。

1. 为会话签发/验证、统一失败、读写鉴权分离及客户端令牌上报添加失败测试；实现 `dashboard/session.py`、更新 `dashboard/api.py`、`server.py` 和客户端。
2. 新建 `web/login.html`，手机视口和真实浏览器验证首次登录、再次打开、拒绝非法登录及任务深链；正式看板继续读取真实数据。
3. 更新 Windows 开发启动、VPS 发布环境校验与 Nginx locations；私有随机密码、会话密钥在仓库外保存，代码和文档仅用占位符。
4. 更新 API、运行与安全文档，执行必要测试与独立审查。dev CI、main CI 通过后固定 SHA 发布，验证公网会话与令牌上报；记录本项目新阶段进度。
